# UI 设计基线

日期：2026-10-25

## 设计方向

主 Skill：`taste-skill:high-end-visual-design`

辅助 Skill：`taste-skill:minimalist-ui`

采用“软结构主义 + 轻微 Z 轴悬挂”：

- 晾衣绳使用低饱和深色薄层、清晰下垂的细绳和带轻量立体感的木质夹子。
- 图片卡片以内容为视觉重点，使用小圆角、细边框和低透明度柔和阴影。
- 设置页使用浅色 Windows 工作区、深色品牌侧栏和单一青绿色强调色。
- 交互状态依赖边框、层级和明暗变化，不堆叠显眼按钮。
- 动画以 140-190ms 的短时展开、收起和控件状态过渡为主，不阻塞操作。
- 不采用 Skill 中偏网页展示的大面积留白、夸张纵深、滚动入场或装饰性渐变。

## 主题资源

统一资源位于 `src/LiangTu.App/Themes/LiangTuTheme.xaml`：

- 中性浅色、深色与强调色
- 字体、控件间距、圆角与柔和阴影
- 主按钮、次级按钮、安静按钮、输入框和开关
- 卡片、菜单、提示和窗口基础样式

窗口只保留与布局相关的局部尺寸；结构颜色、字体、圆角和阴影不再逐窗口硬编码。

## 产品图标

产品图标由 `tools/Generate-AppIcon.ps1` 生成，采用：

- 深灰圆角应用瓦片
- 一根暖白、轻微下垂的绳子
- 单张青绿山景照片和简洁夹子
- 与界面一致的暖白、青绿和少量暖黄

图标只保留一个主体，避免在 16px 托盘尺寸出现多卡片堆叠。ICO 同时包含七个尺寸，并接入 EXE、窗口和托盘。

## 透明悬挂层

- `RopeWindow` 使用 `AllowsTransparency` 和空背景，只绘制绳子、木夹、图片卡片、左侧名称和右侧篮子入口。
- 设置入口只保留在系统托盘，不再占用晾衣绳空间。
- 图片由 `RoundedImage` 自绘并裁切圆角；深色外框、暖白内沿和局部高光共同形成液体玻璃相框。
- 相框根据截图宽高比在固定边界内计算显示尺寸，竖图、横图和近方图使用不同的卡片比例。
- 木夹使用双木片、金属弹簧和顶部挂绳结构；图片库以挂在绳末的篮子呈现。
- 完全透明的像素不接收鼠标，空白区域实际命中了底层 Explorer；图片区域仍命中晾图。
- 收起时内容窗口整体移动到主显示器上方外侧，不使用整窗淡出或背景遮罩。
- 独立 `HotZoneWindow` 始终位于屏幕顶边，只占 7 像素；1/255 透明命中层确保整条顶边可唤出，视觉上不可见。
- 热区窗口使用 `WS_EX_NOACTIVATE`，实测唤出前后当前前台应用进程保持不变。

## 垂落动画

- 内容窗口从 `Top = -188` 进入，目标为 `Top = 0`。
- 使用约 380ms 的窗口坐标关键帧：下降到 `+5`，回收至 `-1`，稳定在 `0`。
- 绳弧使用固定且清晰可见的下垂曲线，不随图片数量、排序或滚动位置改变；图片、木夹和绳子作为一个窗口整体移动。
- 新截图进入晾衣绳时，卡片和木夹从上方落至绳线，带一次轻微回弹；减少动态效果开启时直接落位。
- 收起动画约 230ms，完成后保留顶部热区。
- 关闭“垂落与回弹动画”或 Windows 减少动态效果生效时，直接切换窗口坐标，交互和自动隐藏语义不变。

## 交互验收

- 鼠标停留在卡片上超过测试时限时保持展开；离开后重新计算完整隐藏时间。
- 短拖图片可以持久化排序，当前目标使用细描边和轻微上移提示。
- 单击复制原图，右键立即打开标注；晾衣绳不再显示图片右键菜单。
- 长按约 420ms 后，向上留在绳内可调整位置，向下或拖出窗口可把图片钉到桌面。
- 点击木夹可立即取下图片；桌面钉图左上角显示图钉，点击后挂回晾衣绳并关闭贴图。
- 每张晾衣绳图片左上角显示删除按钮；图片库支持扩展多选与批量删除。
- 拖拽到资料管理器或其他应用使用只复制语义，晾衣绳原图和数据库记录保持不变。
- 拖拽、右键标注、编辑器、图片库和钉取交互期间均暂停自动隐藏。
