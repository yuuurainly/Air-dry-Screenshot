## 一致性关键点

- 自动隐藏只改变晾衣绳窗口状态，不停止图片收集、不删除资源。
- 交互期间状态机暂停计时；所有交互结束后重新开始完整的自动隐藏时间。
- 编辑器取消不写文件；保存失败保留原图；数据库与文件不一致时通过恢复日志处理。
- 缩略图是纯缓存，删除后可重建。
- 贴图关闭只删除贴图实例，不删除图片资源或晾衣绳记录。
